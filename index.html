자기소개서

채널톡 Data Analyst에 지원하며

1지원동기

채널톡 Growth Strategy팀 공고에서 가장 먼저 눈에 들어온 표현은 "데이터에 머무르지 않고"였습니다.

현 직장에서 전사 데이터 추출과 분석을 전담하면서, 데이터를 정확히 뽑는 일만큼 중요한 것이 따로 있다는 사실을 반복적으로 체감했습니다. 바로 "왜 이 데이터가 필요한가"를 먼저 묻는 일입니다. 예를 들어 같은 '특정 브랜드 매출 분석' 요청이라도, 해당 브랜드의 매출 하락 원인(고객 이탈인지 재구매율 저하인지)을 규명하려는 것인지, 경쟁 브랜드와의 점유율 변화를 보려는 것인지, 신규 PB 브랜드 런칭을 위한 시장성 검토인지에 따라 필요한 데이터의 범위와 구조, 비교 기준이 완전히 달라졌습니다. 요청을 그대로 받아 처리할 때와, 목적을 한 단계 거슬러 올라가 정의한 뒤 처리할 때의 결과물은 질적으로 달랐습니다.

채널톡은 구독 기반 B2B SaaS로 성장해 온 회사이자, 지금은 AI Agent Platform으로의 전환을 진행 중인 회사입니다. 이 전환의 한복판에서 AI 매출의 성장 신호를 데이터로 발굴하고 전략을 설계하는 일이 Data Analyst의 미션이라는 점을, 공고를 읽으며 분명히 이해했습니다.

저는 데이터를 다루는 사람을 넘어, 데이터로 문제를 정의하고 구조를 만들어 온 사람입니다. 그 경험을 채널톡의 성장 전략을 설계하는 자리에서 써보고 싶습니다.

2문제를 정의하고 구조로 해결한 경험

현 직장에서 가장 크게 성장한 경험은 단순히 데이터 요청을 처리하는 것에서 벗어나, 요청의 구조와 목적을 파악하고 재설계한 경험입니다.

폐점 매장의 고객 이동 분석, 신규 오픈 효과 분석, 상권 카니발리제이션 분석 등 표면적인 요청은 모두 달랐지만, 결국 "기준 시점의 충성 고객이 이후 어디로 이동했는가"라는 하나의 구조로 환원된다는 점을 발견했습니다. 이 구조를 파악한 뒤 기준기간·분석기간·매장코드를 변수로 분리한 범용 쿼리를 설계했습니다.

이후 같은 구조가 10건 이상의 케이스에 재활용됐고, 정기지표 사이트에 탑재해 현업 담당자가 직접 데이터를 내려받을 수 있는 셀프서비스 환경까지 구축했습니다.

이 경험에서 배운 것은, 좋은 데이터 분석은 요청에 응답하는 일이 아니라 문제의 본질을 정의하는 일에서 시작된다는 것입니다. 채널톡의 "추상적인 비즈니스 고민을 검증 가능한 가설로 구체화한다"는 역할 설명은, 이 경험과 정확히 같은 결을 가지고 있다고 느꼈습니다.

3생성형 AI를 활용한 분석 생산성 극대화

현재 Gemini 기반 AI 에이전트를 Google Drive와 연동해, 과거 데이터 추출 이력을 자동으로 탐색하고 유사한 쿼리와 분석 항목을 안내하는 개인 에이전트를 직접 설계하고 있습니다.

계기는 단순했습니다. 비슷한 요청이 반복될 때마다 예전에 어떤 쿼리를 썼는지 일일이 찾아야 하는 비효율이 누적됐고, 이를 AI로 풀 수 있겠다고 판단했습니다. 이전에도 어필리에이트 데이터 모니터링 업무에서 BigQuery·Python·Slack API를 엮어 이상치 자동 감지 알림 시스템을 직접 구현한 경험이 있었기에, AI와 자동화를 분석 업무에 접목하는 것은 자연스러운 다음 단계였습니다.

공고의 "생성형 AI 도구를 활용해 코딩·분석 업무의 생산성을 극대화해 본 경험"이라는 문장이, 제가 그동안 만들어 온 작업 방식과 정확히 맞닿아 있다고 생각합니다.

4입사 후 포부

1단계 — 채널톡의 비즈니스 구조와 데이터 환경을 빠르게 파악하는 데 집중하겠습니다. B2B SaaS와 AI 에이전트 비즈니스는 제가 경험해 온 유통 도메인과 지표 구조 자체가 다르기 때문에, 고객 인터뷰와 데이터 탐색을 병행하며 채널톡만의 성장 로직을 체득하는 일을 우선순위에 두겠습니다.

2단계 — BigQuery 데이터 마트 설계와 Dataform 기반 파이프라인 구축에 적극적으로 기여하고 싶습니다. 마트 테이블을 직접 구성해 분석 효율을 끌어올린 경험이 있고, 단일 분석을 넘어 DW 구조 전체를 설계하고 운영하는 역할로 성장하겠다는 목표가 명확합니다.

궁극적으로는 궁극적으로는AI 매출 성장의 기회를 데이터에서 먼저 포착하고, 전략적 과제를 직접 정의하는 사람이 되고 싶습니다. "이 일이 채널톡의 기업가치에 어떻게 기여하는가"를 항상 먼저 묻는 팀의 방식은, 제가 일하고 싶다고 생각해 온 방식과 정확히 같습니다.
